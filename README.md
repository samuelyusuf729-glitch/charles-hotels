# Charles Luxe Hotel Web Application

A fully responsive, interactive frontend web prototype for **Charles Luxe**, featuring room reservations, dining/spa pre-ordering, a user bookings dashboard, and a 24/7 customer service chat widget.

## Features
1. **Room Booking System**: Browse luxury rooms, view pricing and descriptions, and submit reservation details through an interactive modal.
2. **Pre-Order Suite**: Add gourmet dining, drinks, and spa services to a live cart with real-time total calculations.
3. **My Bookings Dashboard**: Keep track of confirmed stays and active pre-orders in one place.
4. **Customer Service Widget**: Floating live chat simulation allowing guests to interact with the concierge at any time.

## How to Run
1. Save all four files (`index.html`, `style.css`, `app.js`, and `README.md`) in the same folder.
2. Open `index.html` in any modern web browser.
